# Java Array Fundamentals Practice Programs

## 📌 Overview
This repository contains a collection of beginner-friendly Java programs designed to strengthen array concepts and improve logical thinking skills. The exercises focus on array manipulation, searching, insertion, deletion, counting techniques, and problem-solving through practical coding examples.

These programs were implemented as part of hands-on technical training to gain practical experience with Java arrays and data handling concepts.

## 📚 Topics Covered
- Introduction to Arrays
- Array declaration and initialization
- Input and output of array elements
- Array traversal techniques
- Searching and counting operations
- Array insertion and deletion
- Array manipulation techniques
- Duplicate and unique element handling
- Merging and reversing arrays
- Logical problem-solving using arrays

## 📝 Programs Included

### Basic Array Programs
- Input and print array elements
- Find the sum of all array elements
- Find maximum and minimum elements in an array
- Find the second largest element in an array
- Count even and odd elements
- Count negative elements in an array

### Array Manipulation Programs
- Copy all elements from one array to another
- Insert an element at a given position
- Delete an element from a given position
- Merge two arrays into a third array
- Reverse an array

### Frequency & Duplicate Programs
- Count frequency of each element
- Print unique elements in an array
- Count duplicate elements
- Delete duplicate elements from an array

## 🎯 Learning Outcomes
By completing these programs, you will understand:

- Java array syntax and structure
- Array traversal using loops
- Searching and counting techniques
- Data manipulation in arrays
- Insertion and deletion logic
- Duplicate and unique value handling
- Problem-solving using arrays
- Logic-building through practical programming exercises
